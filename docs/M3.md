# M3: shared rocks ("cells")

Goal: two or three players flying near each other see **the same asteroids, in the same places, moving the same way**,
and their ships collide with them consistently. Spec background: [SPEC.md](SPEC.md) sections *Decisions*,
*Game-side seams* and *Replication model*. Mining and damage between players is M4; M3 only has to keep it from
desyncing (members never fracture a rock locally).

## Gate

On `tools/dev3.sh` (R: ENet relay at the title screen; A at the dive target, B 5,000 px off, C 60,000 px off and warping in after 25 s):

1. A and B form a cell within 2 s of both diving; the lower of their ids is authority (ENet client ids are random). C is alone.
2. Screen captures of A and B framed on the same spot show the same rocks (same shapes, same places, within ~20 px).
3. For 60 s, the rock nearest B agrees between A's and B's logs within 50 px (log both every 5 s by net id).
4. C warps (`--coop-warp-to-peer`) to 20,000 px: C joins the cell, its own rocks go, A's appear, no crash,
   no ship jump > 400 px.
5. The authority quits: the next-lowest id becomes authority of the remaining cell within 1 s and the rocks keep moving for both (no freeze, no mass vanish).
6. Zero `SCRIPT ERROR` lines in any `engine_log.txt`; authority upload logged and under 250 kB/s.

## Interface between Cell and RockSync

Both are children of CoopNet (`get_parent()` / `net`). Each reads the other through these calls only:

```
# Cell.gd provides
func inCell() -> bool                # this machine is in a cell with at least one other player
func isAuthority() -> bool           # true when alone too (you simulate your own bubble)
func authority() -> int              # peer id of the cell authority (myId when alone)
func members() -> Array              # peer ids in the cell, including me; [myId] when alone
func gen() -> int                    # origin generation; RockSync tags every r.* packet with it and drops stale ones
signal cell_joined(authority_id)     # emitted AFTER origin adoption and spawner suspend (member) or on promotion
signal cell_left()                   # back to a solo bubble; spawner resumed
signal authority_changed(new_id)     # handoff inside a live cell

# RockSync.gd provides
func trackedCount() -> int
func releaseAll()                    # member leaving a cell: free tracked rocks (the spawner refills)
func promoteToAuthority()            # handoff: tracked rocks become locally simulated and start streaming
```

RockSync connects to Cell's three signals itself and calls its own `releaseAll` / `promoteToAuthority`; Cell never
frees rocks. A leaving player sends `bye` on quit; Cell also treats an authority silent for 0.9 s on its 5 Hz
`c.hb` as gone.

## Packets (CoopNet `net.on("<type>", self, "<method>")`, sent with `net.send` / `net.sendTo`)

All positions inside a cell are **origin-relative** (`global_position` after adopting the authority's
`CurrentGame.globalOffset`). Beacons stay global.

| Type | Who → who | Reliable | Body |
| --- | --- | --- | --- |
| `c.state` | authority → members | yes, on change and every 2 s | `cid`, `auth`, `members`, `off` (authority's globalOffset), `gen` (origin generation, +1 per slipstream) |
| `c.join` / `c.leave` | member → authority | yes | `gen` seen |
| `c.hb` | authority → members | no, 5 Hz | heartbeat |
| `r.s` | authority → member | yes | list of rock recipes (spawn); batched, max ~200 per packet |
| `r.d` | authority → member | yes | list of net ids (despawn / fractured) |
| `r.u` | authority → member | no | list of `[id, p, r, v, w]`; per receiver 10 Hz within 6,000 px of its ship, 2 Hz to 30,000 px, none beyond |
| `r.snap` | authority → new member | yes | `r.s` for every body within 30,000 px of the member, sent on `c.join` |

Net id = `"<owner peer id>:<counter>"` string; minted by whoever spawns. A rock recipe is whatever the stock spawner
needs to rebuild an identical rock (class, scene/blueprint, scale, mass, ore/vein, seed for its shape, transform,
velocities). Finding that set in `reference/AsteroidSpawner.gd` and `reference/asteroids/asteroid.gd` is the rocks
agent's first job; write it here when known.

## Rules

- All network state is applied on the physics tick (CoopNet already calls modules from `_physics_process`).
- Members never spawn, fracture or despawn a tracked rock on their own. Authority messages only.
- Alone, nothing changes: the stock game runs untouched (Definition of done #9).
- Every new `ext/` script starts `extends "res://<original>"` and calls the parent for everything it doesn't change.
- `python tools/verify.py` must pass; run `python tools/verify.py --update` after changing files and commit the manifest.
